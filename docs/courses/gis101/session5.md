# آموزش ArcGIS Pro: قاب‌بندی (Layout)

## مرحله ۱: ایجاد یک Layout جدید

1. پروژه‌ی خود را در ArcGIS Pro باز کنید.  
2. از نوار بالا به تب Insert بروید.  
3. گزینه‌ی New Layout را انتخاب کنید و اندازه‌ی کاغذ را مشخص کنید (مثلاً A4 Portrait).  
4. یک صفحه‌ی جدید باز می‌شود که محیط کار Layout شماست.

---

## مرحله ۲: افزودن Map Frame

1. در تب Insert روی گزینه‌ی Map Frame کلیک کنید.  
2. از منوی بازشده، نقشه‌ی موردنظر خود را انتخاب کنید (مثلاً Map).  
3. روی Layout کلیک کرده و بکشید تا محل نمایش نقشه تعیین شود.  
4. برای ویرایش محتوا یا تغییر مقیاس نقشه، ابتدا باید نقشه را Activate کنید:  
   - روی Map Frame راست‌کلیک کنید و گزینه‌ی Activate را بزنید.  
   - بعد از انجام تغییرات، از بالا گزینه‌ی Close Activation را انتخاب کنید تا به Layout برگردید.

---

## مرحله ۳: افزودن Scale Bar

1. در تب Insert روی Scale Bar کلیک کنید.  
2. یک مدل نوار مقیاس انتخاب کنید (مثلاً Alternating Scale Bar 1).  
3. در هر نقطه از Layout که می‌خواهید نوار مقیاس قرار گیرد کلیک کنید.  
4. از پنل Element یا Properties می‌توانید موقعیت، اندازه و نوع نوار را تنظیم کنید.  
5. نکته: مقدار نوار مقیاس هرچه باشد، متن عددی آن به‌صورت خودکار (پویا) با مقیاس نقشه هماهنگ می‌شود.

---

## مرحله ۴: افزودن Legend (راهنمای لایه‌ها)

1. در تب Insert روی Legend کلیک کنید.  
2. در محل دلخواه روی Layout کلیک کنید تا Legend اضافه شود.  
3. این قسمت به‌صورت خودکار لایه‌های قابل‌مشاهده‌ی نقشه را نمایش می‌دهد.  
4. در بخش Properties می‌توانید تنظیمات زیر را تغییر دهید:
   - عنوان Legend  
   - ترتیب یا نمایش لایه‌ها  
   - اندازه و فاصله‌ی خطوط  
   - فونت و رنگ متن‌ها  

---

## مرحله ۵: افزودن عناصر نقشه

برای کامل‌تر کردن نقشه، می‌توانید عناصر زیر را اضافه کنید:

- جهت شمال (North Arrow): از مسیر Insert > North Arrow  
- عنوان یا متن (Title/Text): از مسیر Insert > Text  
- کادر دور نقشه (Neatline): از مسیر Insert > Neatline  

---

## مرحله ۶: خروجی گرفتن به JPEG

1. از تب Share روی گزینه‌ی Export Layout کلیک کنید.  
2. در پنجره‌ی بازشده:
   - نوع فایل را روی JPEG (*.jpg) بگذارید.  
   - وضوح تصویر را انتخاب کنید (پیشنهاد: 300 DPI برای کیفیت چاپ).  
   - مسیر ذخیره و نام فایل را مشخص کنید.  
3. روی Export کلیک کنید.

حالا Layout شما به صورت تصویر JPEG ذخیره شده و آماده‌ی اشتراک یا چاپ است.
