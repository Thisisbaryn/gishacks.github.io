# قاب‌بندی پیشرفته در ArcGIS Pro

در این آموزش یاد می‌گیریم چگونه می‌توان در یک پروژه ArcGIS Pro:  

- چند Map مختلف داشت که هرکدام داده‌های متفاوت را نمایش می‌دهند  
- برای هر Map یک Layout جداگانه ساخت  
- از یک Map بزرگ‌تر، یک بخش خاص را جدا کرد (Export Features)  
- برای نقشه کاربری زمین از رنگ‌های استاندارد استفاده کرد و آن‌ها را سفارشی نمود  
- گرافیک و ظاهر نقشه‌ها را به شکل حرفه‌ای تنظیم کرد.

---

## مرحله ۱: ایجاد چند Map در یک پروژه

1. پروژه خود را در ArcGIS Pro باز کنید.  
2. از تب **Insert** گزینه **New Map** را انتخاب کنید.  
3. Map جدید در **Contents Pane** اضافه می‌شود و می‌توانید نام آن را تغییر دهید (مثلاً: کاربری زمین، راه‌ها، تراکم جمعیت).  
4. برای هر Map می‌توانید لایه‌های متفاوت اضافه کنید:
   - Map اول: کاربری‌های زمین (Land Use)  
   - Map دوم: شبکه راه‌ها (Road Network)  
   - Map سوم: نقاط تجمع یا تراکم جمعیت  

> **توضیح تکمیلی:** هر Map مستقل است و تغییرات روی یک Map، Mapهای دیگر را تحت تاثیر قرار نمی‌دهد. این کمک می‌کند تحلیل‌ها و گرافیک هر نقشه جداگانه مدیریت شود.

---

## مرحله ۲: ساخت Layout برای هر Map

1. Map موردنظر را در **Contents Pane** فعال کنید.  
2. از تب **Insert** روی **New Layout** کلیک کنید و اندازه کاغذ را مشخص کنید (مثلاً A4 Portrait).  
3. از **Map Frame**، Map فعال را روی Layout قرار دهید.  
4. برای هر Layout می‌توانید المان‌های زیر را اضافه کنید:
   - **Legend**: راهنمای لایه‌ها  
   - **Scale Bar**: نوار مقیاس  
   - **North Arrow**: جهت شمال  
   - **Text/Title**: عنوان یا توضیح نقشه  

> **توضیح تکمیلی:** در Layout می‌توانید **گرافیک و ظاهر المان‌ها** را تغییر دهید: فونت، رنگ، ضخامت خطوط، شفافیت و موقعیت روی صفحه. این امکان به شما کمک می‌کند نقشه نهایی خواناتر باشد.

---

## مرحله ۳: جدا کردن بخش خاصی از Map با Export Features

برای نمایش بخش خاصی از یک Map بزرگ‌تر (مثلاً منطقه ۶ تهران)، می‌توان از ابزار **Export Features** استفاده کرد:

1. لایه محدوده موردنظر خود را داشته باشید (مثلاً District Boundaries).  
2. منطقه‌ای که می‌خواهید جدا کنید را انتخاب کنید:
   - از ابزار **Select By Attributes** یا **Select By Location** استفاده کنید.  
   - مثال: `DistrictName = '6'`  
3. روی لایه راست‌کلیک کنید و **Data → Export Features** را انتخاب کنید.  
4. در پنجره Export Features:
   - **Input Features:** همان لایه اصلی  
   - **Output Feature Class:** مسیر و نام فایل خروجی (مثلاً Region6.shp یا Region6.gdb)  
5. روی **OK** کلیک کنید. لایه جدید فقط شامل بخش انتخاب شده خواهد بود.  
6. این لایه جدید را می‌توانید به Map یا Layout اضافه کنید تا فقط آن بخش نمایش داده شود.

> **توضیح تکمیلی:** استفاده از Export Features باعث می‌شود داده‌های اصلی دست نخورده باقی بمانند و مدیریت نقشه‌های بزرگ ساده‌تر شود. همچنین می‌توان روی این لایه جدید Symbology و Layout دلخواه اعمال کرد.

---

## مرحله ۴: رنگ‌بندی کاربری زمین و تغییر گرافیک

1. روی لایه کاربری زمین (Land Use) راست‌کلیک کرده و **Symbology** را انتخاب کنید.  
2. گزینه **Unique Values** یا **Categorized** را انتخاب کنید.  
3. در جدول **Attribute Table** ستون نوع کاربری (Land Use Type) را بررسی کنید تا نوع داده مشخص باشد ( کاربری‌ها ذیل label قرار گرفته‌اند، لذا برای تغییر رنگ کاربری‌ها، Field را روی label بگذارید). 
   - مثال: Residential, Commercial, Industrial, Green Space  
4. اگر می‌خواهید رنگ‌ها را تغییر دهید، روی نماد رنگ در Symbology کلیک کرده و رنگ دلخواه خود را انتخاب کنید.  
5. سایر ویژگی‌های گرافیکی قابل تغییر:
   - **Symbol Shape:** شکل نمادها برای کلاس‌های مختلف  
   - **Transparency:** شفافیت لایه‌ها  
   - **Outline Color & Width:** رنگ و ضخامت خطوط مرز  
   - **Labels:** افزودن برچسب‌ها و تغییر فونت، رنگ و اندازه  

> **توضیح تکمیلی:** استفاده از رنگ‌های استاندارد کاربری زمین باعث می‌شود نقشه شما حرفه‌ای و قابل فهم باشد. بررسی Attribute Table قبل از اعمال رنگ‌ها کمک می‌کند مطمئن شوید داده‌ها صحیح و مطابق با کلاس‌بندی هستند.
